Permanent Container Tabs adds a Reopen Tab in Container action: trivially reopen the current tab in a different container without leaving the old tab behind.

If you have [Temporary Containers](https://addons.mozilla.org/en-US/firefox/addon/temporary-containers/) installed, only your permanent containers are displayed.


What Permanent Container Tabs adds to the right-click menu:

- Reopen Tab in Container — closes the current tab and opens a new one at the same URL in your chosen container
- Open in New Container Tab — available on link and bookmark right-clicks; opens the target directly in a container without disturbing the current tab
- Alternate submenu — one action lives at the top level of the context menu; the other is nested one level down; the settings page lets you pick which is which
- Temporary Container entry — if [Temporary Containers](https://addons.mozilla.org/en-US/firefox/addon/temporary-containers/) or [Temporary Containers Plus](https://addons.mozilla.org/en-US/firefox/addon/temporary-containers-plus/) is installed, a "Temporary Container" option appears in every container picker so you can still reach disposable containers from the same menu
- Isolation notice — when [Temporary Containers](https://addons.mozilla.org/en-US/firefox/addon/temporary-containers/) global isolation mode silently intercepts a reopen and redirects it into a throwaway container, Permanent Container Tabs detects it and opens a brief explanation page; can be turned off in settings


Works standalone or alongside [Temporary Containers](https://addons.mozilla.org/en-US/firefox/addon/temporary-containers/) and [Temporary Containers Plus](https://addons.mozilla.org/en-US/firefox/addon/temporary-containers-plus/). Neither is required.


Privacy: Permanent Container Tabs does not collect, transmit, or store anything beyond your local settings. No network requests. No telemetry. Everything stays on your machine.
